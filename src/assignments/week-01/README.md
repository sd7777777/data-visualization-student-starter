# Week 01 - Repository Setup

This directory is the modified Week 1 assignment required by the course starter repository. `PartDFieldNotes.tsx` is the live interactive experience and `analysis-charts.tsx` contains its D3 visualizations.

The root `app/page.tsx` is intentionally a thin route wrapper around this assignment component. That keeps the public site on its existing multi-page architecture while making the substantive Week 1 work live in the upstream starter's required path.

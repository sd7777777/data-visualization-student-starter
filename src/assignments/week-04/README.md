# Week 04 — Legibility and Validation

`LegibilityScatter.tsx` is a copy-and-revision of the Week 03 scatterplot. The original component remains in `week-01/analysis-charts.tsx` and is exported by `week-03/FirstVisual.tsx` for comparison.

Changes: an in-SVG title, larger axes and ticks, collision-filtered tick labels, a plot-boundary clip, an explicit scale choice for the economics view, 1×/2×/4× zoom centered on the selected specialty, and a hover label that disappears on pointer exit or blur. The selected specialty remains in the adjacent inspection panel.

The page ends with a **Validation** section that maps Munzner's four levels to proposed checks for a healthcare analyst. These are hypotheses, not claims of completed testing.

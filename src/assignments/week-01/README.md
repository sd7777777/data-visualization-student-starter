# Week 01 - Repository Setup

This directory is the modified Week 1 assignment required by the course starter repository. `PartDFieldNotes.tsx` is the live one-page experience and `analysis-charts.tsx` contains its D3 visualizations.

The root `app/page.tsx` is intentionally a thin route wrapper around this assignment component. The Week 2 and Week 3 milestones appear as labeled anchors on the same public page, while their source folders remain separate for grading and future edits.

# Week 2 Discord post draft

For Week 2, I used the larger public **Bee Colonies** dataset from TidyTuesday, based on USDA/NASS survey data from 2015 through April–June 2021. The CSV contains 1,222 quarterly records, including Ohio, with managed colony counts, losses, additions, renovations, and percentages. My frontend loads the file from `public/data/bee-colony-loss`, parses it in the browser, and displays the row/column summary, an Ohio-first state filter, a quarterly loss trend, and a colony concentration view.

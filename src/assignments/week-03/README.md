# Week 03 - First Visual

The first graphical representation is the interactive specialty scatterplot exported as `FirstVisual`. Its original implementation is preserved in `week-01/analysis-charts.tsx`. The public `#week-3` section now displays its Week 04 revision; see `week-04/LegibilityScatter.tsx` for the copied and improved version. The original cost-and-volume view uses D3 logarithmic position scales; its drug-category view uses zero-based linear scales. Circle area uses a square-root scale, and every mark supports pointer and keyboard inspection.
